One cat joke, one line, under 200 characters — picked from 18 candidates scored against the judge's published brief (setup with a turn that lands, a laugh on the first read, a fresh angle, tight wording, retellable the same day). The winner: a work-from-home cat unmutes its human mid-meow, and the boss concludes a very small, very rude employee is on the payroll.

## Run it

```sh
node main.ts
```

Writes the joke to `/output/entry.txt` (`$OUTPUT_DIR` overrides the directory). Node 22+, no dependencies. Deterministic, no network, no model calls.
